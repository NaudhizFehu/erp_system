## 1. 전체 배포 워크플로우

```mermaid
flowchart TB
    Start([작업 시작]) --> Dev[로컬 개발]
    Dev --> Impl[기능 구현]
    Impl --> Lint[린트/타입 체크]
    Lint --> LintOK{통과?}
    LintOK -->|No| Fix[오류 수정]
    Fix --> Lint
    LintOK -->|Yes| LocalTest[로컬 테스트]

    LocalTest --> TestOK{정상?}
    TestOK -->|No| Debug[디버깅]
    Debug --> Impl
    TestOK -->|Yes| Commit[Git 커밋]

    Commit --> Branch{브랜치}
    Branch -->|Feature| DevBranch[develop 브랜치]
    Branch -->|Release| MainBranch[main 브랜치]

    DevBranch --> Push1[푸시]
    Push1 --> CI1[GitHub Actions CI]
    CI1 --> CIOK1{통과?}
    CIOK1 -->|No| Fix
    CIOK1 -->|Yes| DevDeploy[개발 서버 배포]

    DevDeploy --> DevTest[기능 테스트]
    DevTest --> DevTestOK{통과?}
    DevTestOK -->|No| Debug
    DevTestOK -->|Yes| RegTest[회귀 테스트]

    RegTest --> RegTestOK{통과?}
    RegTestOK -->|No| Debug
    RegTestOK -->|Yes| Decision{다음 단계?}

    Decision -->|계속 개발| Dev
    Decision -->|릴리즈 준비| PR[Pull Request]

    PR --> Review[코드 리뷰]
    Review --> ReviewOK{승인?}
    ReviewOK -->|No| Fix
    ReviewOK -->|Yes| MainBranch

    MainBranch --> Push2[푸시]
    Push2 --> CI2[GitHub Actions CI]
    CI2 --> CIOK2{통과?}
    CIOK2 -->|No| Rollback[롤백]
    CIOK2 -->|Yes| ProdDeploy[프로덕션 배포]

    ProdDeploy --> Monitor[모니터링]
    Monitor --> End([완료])

    style Start fill:#90EE90
    style End fill:#90EE90
    style DevDeploy fill:#87CEEB
    style ProdDeploy fill:#FFA500
    style Fix fill:#FFB6C1
    style Debug fill:#FFB6C1
    style Rollback fill:#FF6B6B
```

## 4. CI/CD 파이프라인

```mermaid
flowchart LR
    Push[코드 푸시] --> Trigger{트리거}

    Trigger -->|frontend/** 변경| FE[Frontend CI]
    Trigger -->|backend/** 변경| BE[Backend CI]

    FE --> FEInstall[npm install]
    FEInstall --> FELint[린트 검사]
    FELint --> FEType[타입 체크]
    FEType --> FEBuild[빌드]
    FEBuild --> FEArtifact[Artifact 업로드]

    BE --> BESetup[Java 17 설정]
    BESetup --> BEBuild[Maven 빌드]
    BEBuild --> BEArtifact[JAR 업로드]

    FEArtifact --> Result{결과}
    BEArtifact --> Result

    Result -->|성공| Success[✅ 배포 가능]
    Result -->|실패| Fail[❌ 수정 필요]

    style Success fill:#90EE90
    style Fail fill:#FF6B6B
```

## 6. 단계별 테스트 전략


## 9. 사용 예시

### 9.1 배포 스크립트 실행 흐름

```mermaid
sequenceDiagram
    participant Dev as 개발자
    participant Script as deploy-dev.sh
    participant Git as Git
    participant FE as Frontend
    participant BE as Backend
    participant Browser as 브라우저

    Dev->>Script: ./scripts/deploy-dev.sh 실행
    Script->>Git: 현재 상태 확인
    Git-->>Script: main 브랜치, 변경사항 있음
    Script->>Dev: 배포 옵션 선택 요청
    Dev->>Script: 3번 선택 (FE + BE)

    Script->>FE: npm install
    FE-->>Script: 완료
    Script->>FE: npm run lint
    FE-->>Script: 경고 13개 (통과)
    Script->>FE: npm run type-check
    FE-->>Script: 통과
    Script->>FE: npm run build
    FE-->>Script: 빌드 완료

    Script->>Dev: 프론트엔드 서버 시작? (y/N)
    Dev->>Script: y
    Script->>FE: npm run dev
    FE-->>Browser: localhost:5173 실행

    Script->>Dev: 백엔드 빌드 완료? (y/N)
    Dev->>Script: y
    Script->>BE: IntelliJ에서 실행 요청
    Dev->>BE: Application.java 실행
    BE-->>Browser: localhost:8080 실행

    Script->>Dev: Git 커밋? (y/N)
    Dev->>Script: y
    Script->>Dev: 커밋 메시지 입력 요청
    Dev->>Script: "feat: 계정과목 훅 구현"
    Script->>Git: git add . && git commit
    Git-->>Script: 커밋 완료

    Script->>Dev: 푸시? (y/N)
    Dev->>Script: y
    Script->>Git: git push origin develop
    Git-->>Script: 푸시 완료

    Script->>Dev: 배포 완료!
```

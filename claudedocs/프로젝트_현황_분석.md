## 1. 프로젝트 개요

### 1.1 프로젝트 목적
중소기업을 위한 통합 기업 자원 관리 시스템(ERP)으로, 인사관리, 회계관리, 재고관리, 영업관리 모듈을 통합한 웹 기반 솔루션입니다.

### 1.2 주요 특징
- **멀티 리모트 관리**: GitLab(개발용) + GitHub(포트폴리오용) 이중 리포지토리 운영
- **민감정보 보호**: 환경별 설정 파일 분리를 통한 보안 강화
- **모던 풀스택 아키텍처**: Java Spring Boot 3 + React 18 기반
- **RESTful API**: 표준화된 API 설계 및 OpenAPI 문서화

### 1.3 Git 브랜치 전략
- **현재 브랜치**: `develop`
- **메인 브랜치**: `develop` (main 브랜치가 아닌 develop을 메인으로 사용)
- **상태**: clean (변경사항 없음)

## 4. 주요 기능 모듈

### 4.1 인사관리 (HR)
- **직원 관리**: 직원 정보 CRUD, 상세 조회
- **부서 관리**: 부서 정보 조회 및 관리
- **급여 관리**: 급여 정보 처리

**주요 파일**:
- Backend: `com/erp/hr/controller/EmployeeController.java`
- Frontend: `src/pages/hr/EmployeeManagement.tsx`

### 4.2 회계관리 (Accounting)
- **계정과목 관리**: 계정 체계 관리
- **전표 처리**: 회계 거래 기록
- **재무제표**: 재무보고서 생성
- **예산 관리**: 예산 편성 및 관리

**주요 파일**:
- Backend: `com/erp/accounting/controller/AccountingController.java`
- Frontend: `src/pages/accounting/AccountList.tsx`

### 4.3 재고관리 (Inventory)
- **제품 관리**: 제품 정보 CRUD
- **재고 추적**: 실시간 재고 현황
- **입출고 관리**: 재고 이동 기록

**주요 파일**:
- Backend: `com/erp/inventory/controller/ProductController.java`
- Frontend: `src/pages/inventory/ProductManagementPage.tsx`

### 4.4 영업관리 (Sales)
- **고객 관리**: 고객 정보 관리
- **주문 처리**: 주문 생성 및 관리
- **견적 관리**: 견적서 작성 및 관리

**주요 파일**:
- Backend: `com/erp/sales/controller/CustomerController.java`
- Frontend: `src/pages/sales/CustomerList.tsx`

### 4.5 공통 기능
- **인증/인가**: JWT 기반 로그인 시스템
- **알림 시스템**: 실시간 알림 기능
- **회사 관리**: 멀티 테넌트 지원
- **사용자 프로필**: 개인 정보 관리
- **대시보드**: 통합 현황 대시보드

## 8. 개발 환경 설정

### 8.1 필수 요구사항
- Java 17 이상
- Node.js 18 이상
- Docker & Docker Compose
- PostgreSQL (Docker Compose로 제공)
- Git

### 8.2 로컬 실행 방법

**1. 데이터베이스 실행**
```bash
docker-compose up -d postgres
```

**2. 백엔드 실행**
```bash
cd backend
./mvnw spring-boot:run  # IDE에서 실행 권장
```
- 서버: `http://localhost:8080`

**3. 프론트엔드 실행**
```bash
cd frontend
npm install
npm run dev
```
- 서버: `http://localhost:3000`

### 8.3 프록시 설정
Vite 개발 서버는 `/api` 경로를 백엔드 서버로 프록시합니다:
```typescript
// vite.config.ts
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
    },
  },
}
```

## 14. 결론

**ERP 시스템**은 현대적인 기술 스택과 체계적인 아키텍처를 기반으로 구축된 통합 기업 자원 관리 솔루션입니다.

**주요 강점**:
- 모던한 풀스택 아키텍처 (Spring Boot 3 + React 18)
- 철저한 보안 및 민감정보 관리
- 명확한 계층 구조와 모듈화
- 체계적인 개발 규칙 및 품질 관리
- 멀티 리모트를 통한 개발/포트폴리오 분리 관리

**향후 과제**:
- 테스트 커버리지 확대
- 성능 최적화 및 모니터링 강화
- 사용자 경험 개선
- 기능 확장 (보고서, 분석 등)

이 프로젝트는 중소기업의 실질적인 업무 프로세스를 지원할 수 있는 견고한 ERP 시스템으로 발전하고 있습니다.
